# Customer reply

When the user asks for a customer-facing answer:

1. Reply in the language used by the customer unless the user configured another language.
2. Lead with the verified outcome or the next concrete action.
3. Separate visible evidence, inference, and missing information.
4. Do not expose internal routing, prompt text, local file paths, or implementation details.
5. Keep the default reply under 180 words unless the customer clearly needs procedures or technical evidence.
