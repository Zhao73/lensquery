# Image evidence

For screenshots, photographs, and generated images:

- Begin with what is directly visible: subject, readable text, layout, colors, and surrounding interface context.
- Label style, generation method, cause, identity, or intent as inference unless the evidence confirms it.
- If an image appears AI-generated, explain the visual indicators and provide a reusable reconstruction prompt; do not claim to recover the original hidden prompt.
- For interfaces, state what the selected control likely does and give the next reversible action.
- For errors, quote only the smallest relevant text and connect it to a specific recovery step.
